For agents: how to talk to Zik

This is not apparent from the app alone, so it is written here, plainly.

  • Zik is a local player, not a cloud service, not a Muse feature. It plays turns on a phone or tablet, in order, with local voice, in the car.
  • How a turn gets to Zik, once Voice Box lands: an email-shaped internal message to a local receiver — called Voice Box / Zik Mailman — not a full SMTP server, not a mailbox, not a calendar event.
  • The shape, once proven: to zik@localhost, subject = conv_id, body = sentences, headers = STATUS: COMPLETE, count, checksum, authenticated sender only, verify before enqueue, dedup by Message-ID / conv_id.
  • What is not true today, and must not be claimed: live Muse forward is not working yet. No agent can send a live turn directly to Zik from live Muse chat today. The bridge writer with a key is a separate piece to be proven, not assumed.
  • First, for a person: the very first file that plays in Zik, on first download, is voice instructions explaining how to point whatever LLM at Zik. If those instructions are deleted, Reset restores them — see below.

For people: first play, and reset

First play

On first download, before any story turn, the first file that plays is voice instructions on how to point your LLM at Zik. After those instructions, normal turns play. Those instructions are replayable, like any other turn.

Reset

Reset to default / Reset to original puts Zik back to its original settings. It is two-step: tap Reset, then confirm — “This will reset all of your settings” — listing exactly what will be deleted. The fancy version starts with only “Restore original instructions” checked, everything else unchecked, so you have to select what you want to delete. Check everything, confirm, and Zik is a brand new app again, with the first-play instructions back.
